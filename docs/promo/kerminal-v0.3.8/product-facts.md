## 视频可用表述

- Kerminal 是本地桌面终端、远程管理与 Agent 工作台。
- 支持本机、SSH、RDP、Telnet、串口与容器目标。
- 支持多标签、多分屏终端。
- 支持启动 Codex、Claude Code 与自定义命令行 Agent，并绑定当前目标。
- 支持 SFTP 文件浏览、传输与远程文本编辑。
- 支持 Docker、Podman、Compose、容器日志、终端与文件管理。
- 支持服务器资源监控、SSH 端口转发与 tmux。
