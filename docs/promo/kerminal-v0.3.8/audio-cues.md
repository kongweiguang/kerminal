# 音频 Cue

| 时间 | 类型 | 作用 |
| --- | --- | --- |
| 0.10s | `logo-reveal-v2` | Logo 与终端光标建立 |
| 2.75s | `whoosh-fast` | Logo 展开为完整工作台 |
| 7.65s | `focus` | 焦点移动到 Agent |
| 13.05s | `whoosh-fast` | 工作台切入 SFTP |
| 18.05s | `command-execute` | 容器与 Compose 状态出现 |
| 22.45s | `focus` | 系统资源与当前目标聚焦 |
| 26.20s | `complete-done` | 品牌结尾收束 |

BGM 使用 `bgm-ad.mp3`，人声优先；BGM 约 -22dB，SFX 约 -12dB，并在最终混音后限制峰值。
