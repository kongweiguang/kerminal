# 原型类型

## Logic 原型

- 用于状态机、业务规则、权限分支、队列或任务流。
- 提供一条命令和 3 到 5 个关键场景。
- 每步展示关键状态、输入、输出和错误。
- 使用临时或内存数据，不连接生产。

## UI 原型

- 使用现有前端栈、组件和路由，不另建无关 demo app。
- 一个入口切换多个方案，所有变体使用同一数据集和 viewport。
- 验证布局、信息层级、交互状态、键盘、窄屏和失败状态，而非只做静态外观。
- 原型说明不进入正式产品 UI。

## Spike 原型

- 用于库、协议、外部服务、构建、平台或性能可行性。
- 记录版本、最小配置、权限、许可证、部署影响和失败限制。
- 使用 mock/sandbox/staging；外部写入仍需授权。
- 结论必须能转成采用/拒绝决策和正式验证计划。

## 收口矩阵

| 结果 | 动作 |
| --- | --- |
| 证明可行 | 删除原型并把决策、边界和生产任务写入 plan |
| 代码可复用 | 吸收进正式模块，去掉标记并补错误、测试、文档 |
| 证明不可行 | 删除代码，在 discovery 保留证据与拒绝原因 |
| 仍需用户判断 | 保留最小入口，写 owner、过期时间和下一判断点 |
